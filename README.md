# 📈 Crypto Multi-Timeframe Confluence Scanner

اسکنر سیگنال کریپتو با امتیازدهی وزن‌دار ۰–۱۰۰ (۱۰ مؤلفه در ۴ بلوک)، فیلتر تایم‌فریم بالاتر و
مشتق‌گیری هموار با **فیلتر کالمن** (Local Linear Trend).

## اجرای محلی
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ۱) ساخت مخزن GitHub و آپلود فایل‌ها
1. وارد github.com شوید → **New repository** → نام: `crypto-scanner` → Public → Create.
2. در صفحه مخزن: **Add file → Upload files** → همه فایل‌های این پوشه را بکشید و رها کنید →
   **Commit changes**.
   (یا با ترمینال:)
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<USERNAME>/crypto-scanner.git
git push -u origin main
```

## ۲) اتصال Streamlit Cloud به مخزن
1. به https://share.streamlit.io بروید و با GitHub وارد شوید.
2. **Create app → Deploy a public app from GitHub**.
3. Repository: `<USERNAME>/crypto-scanner` — Branch: `main` — Main file path: `app.py`.
4. **Deploy**. آدرسی مثل `https://<app-name>.streamlit.app` می‌گیرید.

## ۳) ساخت آیکون میانبر روی صفحه گوشی (اجرا با یک کلیک)
- **اندروید (Chrome):** آدرس اپ را باز کنید → منوی ⋮ → **Add to Home screen** → Add.
- **آیفون (Safari):** آدرس را باز کنید → دکمه اشتراک‌گذاری → **Add to Home Screen** → Add.
میانبر مثل یک اپ مستقل و تمام‌صفحه اجرا می‌شود.

## فایل‌ها
| فایل | نقش |
|---|---|
| `app.py` | رابط کاربری Streamlit (اسلایدرهای تنظیمات، اسکن، کارت سیگنال) |
| `signal_card.py` | ساخت کارت سیگنال و خلاصه تحلیل تفصیلی فارسی |
| `scoring.py` | موتور امتیازدهی، بلوک‌ها، گیت‌ها، فیلتر HTF، پلن معامله |
| `my_crypto_lib.py` | اندیکاتورها (EMA/RSI/MACD/ADX/ATR/BB/Ichimoku) |
| `kalman.py` | فیلتر کالمن و مشتق هموارشده قیمت |
| `data_sources.py` | رتبه‌بندی نمادها و دریافت OHLCV با fallback صرافی |
| `config.json` | وزن‌ها، آستانه‌ها، تایم‌فریم‌ها |


## نسخه سبک (خروجی فقط کارت سیگنال)
- تمام خروجی‌های سنگین آنلاین (چارت کندل، گیج، رادار، نمودار مؤلفه‌ها، جدول کامل اسکن) حذف شد؛ وابستگی `plotly` نیز حذف شده است.
- خروجی فقط شامل **کارت سیگنال** است که همان لحظه صدور سیگنال نمایش داده می‌شود (سبز = خرید، قرمز = فروش).
- گزینه «توقف در اولین سیگنال» فعال است؛ با زدن «شروع / ادامه اسکن» اسکن از همان رتبه ادامه می‌یابد (دسته‌های ۵۰تایی).
- فلسفه و منطق استراتژی (۱۰ مؤلفه، ۴ بلوک، گیت‌ها، فیلتر کالمن، فیلتر سخت‌گیرانه تایم‌فریم بالاتر، R:R) بدون هیچ تغییری حفظ شده است.

## نسخه ۳ (اصلاحات این به‌روزرسانی)
1. **اصلاح نمایش ترتیب EMA:** رشته توضیح از مقادیر واقعی ساخته می‌شود (مثلاً `20 > 50 > 100 > 200` یا `20 < 50 < 100 < 200`)، پس هیچ توصیف معکوسی رخ نمی‌دهد. عملگرها همیشه با شرط‌های ریاضی کد یکسان‌اند.
2. **تنظیمات کامل با اسلایدر:** «محدوده رتبه بازار»، «آستانه سیگنال» و «حداقل نسبت R:R» همه به `st.slider` تبدیل شده‌اند و هم‌زمان روی اسکن اعمال می‌شوند.
3. **تحلیل تفصیلی بازشدنی:** هر کارت سیگنال یک `st.expander` با عنوان «🔎 تحلیل تفصیلی» دارد که خلاصه چندخطی فارسی از هم‌گرایی عوامل (EMA، ایچیموکو، حجم، RSI/StochRSI/ADX/MACD، شیب کالمن، تایم‌فریم بالاتر، مدیریت ریسک، هشدارها) نمایش می‌دهد — بدون هیچ چارت سنگین.
4. **سبک‌سازی کارت:** خط تکراری «کارت سیگنال خرید/فروش» حذف شد؛ آیکون رنگی و عبارت انتهایی گویا هستند.

منطق ریاضی، نحوه دریافت داده و اجرای استراتژی دست‌نخورده است.
